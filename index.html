The Problem

Today

Lender emails a CD. Title emails theirs back. Someone opens both PDFs and goes line by line. "Your title fee says $275, ours says $300 — same fee?" Three to five email rounds later, maybe hours, maybe days, the numbers finally match. Meanwhile, a family is waiting to move in.

Solution

Both sides upload to one portal. AI reads both documents, spots that "Title Search" and "Title Examination" are the same fee, flags the $25 difference, suggests the fix with an explanation, checks TRID tolerances — and notifies both parties with a magic link. If everything's clean, the balanced CD goes out automatically. Zero rounds, zero emails, seconds not days.

Design Principles
Property as Background
The actual home photo fills the entire viewport. Sourced from MLS API (first choice) or curated property photography (fallback). Every file feels personal.
Minimal Glass UI
One frosted surface, anchored to the bottom. Inspired by Apple's Liquid Glass — the panel floats over the property, not on top of it. No stacked cards, no visual clutter.
Almost No UI
The diff, the AI suggestions, the approve button. That's it. Progress is a single word — not a stepper. Mismatches in red, fixes in green. Like a HUD, not a dashboard.
Emotional Motivation
Both parties see the house and are reminded why they need to balance fast — someone's waiting to move in. The image creates urgency and human connection.
Image Tier System
MLS photo via API when the address matches. Curated property photography as fallback — always premium, always on-brand.
Mobile-Ready Approval
Responsive web works on any device. Open the link → see the house → see the issues → approve. No app install needed. Under 10 seconds for pre-reviewed files.
03 — Authentication

Passwordless Accounts

Fast account creation with no passwords. Users need accounts for history, billing, preferences, and audit compliance — but signup should feel invisible.

Email Magic Link (Default)
Enter email, receive link, click, you're in. Same flow as file invites — users barely realize they've "signed up." Session persists until expiry or logout.
SMS Code
Phone number + 6-digit code. Mortgage people live on phones. Doubles as MFA for security-conscious orgs.
Sign in with Google/Microsoft
One tap. Most title companies and lenders are on Google Workspace or M365. Gets verified name + email automatically for audit trail.
Invisible Onboarding
First interaction: get invited to a file → verify email → you're viewing AND you have an account. No separate signup flow. No password to remember.
Why Accounts Matter
History: past files, search, pending tracking. Billing: payment method tied to user/org. Audit: named identity for every approval. Preferences: saved proration methods, contacts.
Open-Source Auth Stack
Lightweight OSS auth (Auth.js, Lucia, or custom Workers implementation). Magic links + OAuth stored in D1. Sessions via signed tokens. No vendor lock-in, no per-user fees.

Mastra Agent Pipeline

Each upload triggers a workflow on Cloudflare Workers. Clean files go straight through — no human touch. Low-confidence extractions or mismatches route to the human review gate. The Suggestion Agent proposes fixes for every mismatch. All math runs in a deterministic engine — never through the LLM. Both parties are notified at every state change.

Extraction Agent
PDF pages → Claude vision extracts and normalizes line items into typed JSON (Zod schema) with confidence scores per field. Low-confidence fields flagged for human review. Fee mappings cached in KV.
👤
Human Review Gate (Conditional)
Only triggers when extraction confidence is low. Flagged fields shown in amber in the UI. User verifies or corrects inline. High-confidence files skip this step entirely — full automation on the happy path.
⚖️
Reconciliation Agent
Claude fuzzy-matches line items across documents. Deterministic engine handles all math. Flags mismatches and passes them to the Suggestion Agent.
💡
Suggestion Agent
Analyzes each mismatch and proposes a fix: naming normalization, proration method alignment, county fee schedules. Each suggestion includes a plain-English explanation. Powers the red→green UI.
✅
TRID Agent
Checks tolerance buckets (zero, 10%, unlimited). Flags re-disclosure triggers. All rules codified — no LLM ambiguity on compliance.
📋
Report Agent
Generates balanced PDF, plain-English diff summary, and audit trail to D1. Passes result to Notification Agent.
🔔
Notification Agent
Routes alerts based on file state. New upload → email both parties with magic link. Mismatches found → notify reviewer. Approval needed → nudge counterparty. All balanced → "Ready to Schedule" email. Postmark for email, push notifications in Phase 4.
Why Mastra + Cloudflare
TypeScript End-to-End
One language from frontend to agent pipeline. No Python/TS bridge. Mastra agents deploy directly to Cloudflare Workers via @mastra/deployer-cloudflare.
Built-in Workflows
Mastra's typed workflow system handles the Extract → Reconcile → Suggest → TRID → Report → Notify pipeline with branching, error recovery, and human-in-the-loop approval.
79+ LLM Providers
Swap between Claude, GPT-4, Gemini by changing config. Start with Claude for extraction intelligence, A/B test others without rewriting agent logic.
Durable Objects = Per-File State
Each closing file is a Durable Object. Real-time state, WebSocket for live updates, instant approval locking. No race conditions between parties.
R2 = Zero Egress
S3-compatible storage with no egress fees. Serving PDFs to both parties constantly? Free. At scale, this saves thousands vs. AWS S3.
KV = Smart Fee Cache
Fee description mappings cached in KV. "Title Search" = "Title Examination" learned once, applied globally. Cuts LLM calls by 60-70% over time.
05 — Scale Considerations

What Volume Are We Designing For?

The Cloudflare architecture scales naturally — Workers auto-scale, Queues absorb bursts, KV caching reduces cost over time. But target volume shapes decisions around database strategy, LLM spend, and compliance timelines. This is an open question for the client.

Stateless Workers
API and agent workers are stateless and horizontally scalable. Cloudflare auto-scales Workers globally — no capacity planning, no cold starts.
Queue-Based Processing
Upload → job on CF Queue → workers process → push results → notify via Durable Object WebSocket. Scales from a handful of workers to hundreds.
D1 → External Postgres
Start with D1 (Cloudflare's SQLite). When audit log and version history outgrow it, migrate to external Postgres with partitioning. Schema stays the same.
Smart LLM Caching
KV cache learns fee mappings over time. Seen "Title Search" = "Title Examination" before? Skip the LLM. The system gets cheaper as it scales — estimated 60-70% reduction in LLM calls.
06 — Technical Roadmap

Build Phases

Phased approach from MVP to full-scale platform. Same architecture throughout — no re-build between phases.

Phase 1 — Core MVP
Weeks 1–6
Full automation on clean files. Human review only when extraction confidence is low or reconciliation has mismatches. Upload → balanced CD out, hands-off.
Mastra Agent Pipeline
Extract → Auto-reconcile → Suggest fixes → TRID → Report → Notify. Clean files go straight through with no human touch. Low-confidence extractions or mismatches trigger the human review gate. Every mismatch gets an AI-generated fix proposal.
PDF Extraction
Claude vision reads PDF pages directly — no OCR dependency. Confidence scores per field. Low-confidence fields flagged with amber UI for inline editing.
Glass UI (React)
Full-bleed property photos, single frosted glass surface, side-by-side diff. Inline field editing for flagged extractions. Responsive web — works on mobile out of the box.
Auth + File Portal
Passwordless auth via OSS stack. Magic links + OAuth. Secure invite links per file. Durable Objects for per-file real-time state.
Infrastructure
R2 for encrypted PDFs. D1 for data. KV for fee cache. Queues for async. Audit logging from day one. Email notifications via Postmark.
Notification Flow
Event-driven alerts via Postmark. New file → magic link to both parties. Mismatches → reviewer notified. Approval needed → counterparty nudge. All balanced → "Ready to Schedule." Digest mode for high-volume users. Push notifications deferred to Phase 4.
Phase 2 — Collaboration + Insights
Weeks 7–10
In-platform discussion, dual-party approval workflow, AI-suggested fixes, property image pipeline, and a lightweight analytics dashboard.
Line-Item Comments
Threaded discussion per fee line. @mentions. Real-time via Durable Objects WebSocket. Replaces email back-and-forth.
Dual-Party Approval + Audit
Both sides approve → file locks → auto-generate balanced PDF → email "Ready to Schedule." Every action versioned with full audit log.
AI Suggestion UX
One-click accept/reject per suggestion. Batch "Accept All" for clean files. Suggestion history and accuracy tracking. Feedback loop improves future suggestions via KV cache.
Property Image Pipeline
MLS API integration → curated property photography fallback. Image optimization + caching on CF.
Analytics (Lightweight)
Avg time-to-balance, discrepancy frequency, files per user. Simple dashboard built on data the pipeline already captures. Not full-blown — just visibility.
Phase 3 — Integrations
Weeks 11–16
Direct API connections to LOS and title platforms. Billing. SOC2 prep. Eliminate the PDF upload step for connected users.
Encompass API
Auto-pull CD data from ICE Mortgage Technology. Bidirectional sync. Eliminate PDF upload for Encompass users.
Title Platform APIs
Qualia, RamQuest, SoftPro connectors. Pull settlement statements, push balanced figures back.
Billing + SOC2 Type I
Stripe integration ($25-45/closing or monthly tiers). Engage compliance firm for SOC2. Access controls, pen testing, security documentation.
Phase 4 — Scale & Extras
Weeks 17+
Email ingestion, native mobile app (optional), advanced analytics, scale optimizations, and enterprise features.
Email Ingestion
Monitor dedicated inbox. Auto-detect CD attachments. Match to existing files or create new. Zero manual upload.
Flutter Mobile App (Optional)
Native iOS + Android with glass UI. Property photo backgrounds. Push notifications from the Notification Agent. Quick-approve. Only if demand warrants it — responsive web covers mobile until then.
Advanced Analytics
Team performance comparisons, common discrepancy patterns, ops manager dashboards. Full charting and exportable reports.
Scale + Enterprise
D1 → external Postgres if needed. Tiered LLM strategy. SOC2 Type II. Advanced KV caching. White-label API for enterprise partners.

Break-Even
At $35 avg per closing, infrastructure breaks even at roughly 7–23 closings/month. Extremely low threshold to profitability.
No OCR Dependency
Claude handles extraction directly from PDF pages — no Textract or Document AI. Eliminates $150-500/mo in OCR costs and removes an entire external dependency.
Cost Curves Down
KV cache reduces LLM calls 60-70% over time. The more closings processed, the cheaper per-closing becomes. Inverse scaling economics.
